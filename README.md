# 🍀 로또 6/45 라이브 추첨 스튜디오 (Lotto 6/45 Simulation Studio)

실제 생방송 로또 추첨 방송을 보는 듯한 **2D Canvas 물리 엔진 기반 원형 챔버 추첨기**, **공기 송풍 및 와류 물리 시뮬레이션**, **Web Audio API 자체 합성 사운드 효과**, 그리고 **실제 로또 복권 영수증(Slip) 뷰**를 제공하는 웹 애플리케이션입니다.

![Preview](preview.png)

---

## ✨ 주요 기능

1. **실시간 3D 투명 챔버 물리 엔진 (`physics.js`)**
   - 45개의 실시간 탄성 충돌 연산 구체
   - 대한민국 공식 로또 볼 색상 반영 (1~10 노랑, 11~20 파랑, 21~30 빨강, 31~40 회색, 41~45 녹색)
   - 송풍기(Blower) 가동 시 상향 제트 기류 및 소용돌이 와류 물리 시뮬레이션
   - 당첨 번호 추출 시 상단 흡입관으로 빨려 올라오는 연출

2. **순수 브라우저 신디사이저 오디오 엔진 (`audio.js`)**
   - 외부 음원 의존성 제로 (Web Audio API 기반 100% 자체 합성)
   - 바람 송풍음, 공 충돌음, 추출음('퐁!'), 안착 차임벨, 당첨 축하 팡파르
   - 사운드 ON/OFF 음소거 토글 지원

3. **생방송 전광판 & 실시간 통계 (`index.html`, `app.js`)**
   - 6개 본번호 + 보너스 번호 실시간 거치대 안착
   - 실시간 자막 중계 피드
   - 당첨 번호 총합(Sum), 홀:짝 비율, 고:저 비율 실시간 산출
   - 추첨 속도 조절 (1x 표준 속도, 2x 빠른 속도)

4. **실제 로또 영수증(Slip) & 5게임 일괄 추첨 (`style.css`)**
   - 실제 복권방 감열지 영수증 질감 및 지그재그 절취선 디자인
   - 5게임(A~E) 일괄 번호 발행 및 원클릭 클립보드 복사

---

## 🚀 실행 방법

별도의 설치나 빌드 과정 없이, 웹 브라우저에서 `index.html` 파일을 열면 바로 실행할 수 있습니다.

```bash
# 저장소 복제
git clone https://github.com/jongung21-sudo/lotto.git

# 실행: index.html 더블 클릭 또는 로컬 웹 서버 실행
```
